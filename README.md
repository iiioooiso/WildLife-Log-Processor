# 🐾 Wildlife Log Processor

A modern Flask-based web application for uploading and processing wildlife log files. This tool helps you analyze, summarize, and report wildlife activity from raw text logs with ease.

## 🌿 Features

- 📤 Upload `.txt` wildlife logs
- ⚙️ Server-side processing via Flask
- 📊 Generate daily activity reports
- 💡 Clean, modern UI with animated feedback
- 📦 Easily extensible for future analytics (AI tagging, filtering, etc.)

---

## 🚀 Getting Started

### 🔧 Requirements

- Python 3.8+
- `pip` package manager

### 📦 Installation

```bash
# Clone the repository
git clone https://github.com/your-username/wildlife-log-processor.git
cd wildlife-log-processor

# Create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
